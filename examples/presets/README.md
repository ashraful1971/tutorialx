# Tutorial and reel presets

These authored profiles cover every caption mode across tutorial and reel examples: `embedded`, `sidecar`, `both`, and `none`. They also show voice pace/tone/pronunciation controls, a small brand overlay, and explicit no-music/no-effects settings.

Every preset remains in `review` mode. It resolves configuration and supports plan review but never authorizes recording, synthesis, or rendering. The `example-voice@unconfigured` selection is deliberately non-runnable: replace it with an installed compatible provider, rerun preflight and approve the resulting exact plan revision.

Profiles are immutable inputs to a job snapshot. Editing one of these files later does not alter a previously resolved or approved job. Adopt a changed profile through a new plan revision and review the targeted impact report before approving it.
